## 🚀 Быстрый старт

```bash
# Установка
pnpm install

# Сборка всех пакетов
pnpm build

# Создание нового плагина
pnpm gen:plugin
```

## 📦 Структура проекта

```
notehub.md/
├── packages/
│   ├── core/                 # @notehub/core — ядро приложения
│   └── plugins/
│       ├── system/           # Системные плагины
│       ├── ui/               # UI плагины
│       └── features/         # Фича-плагины
├── apps/                     # Приложения
├── scripts/                  # CLI-скрипты
└── docs/                     # Документация
    └── ru/                   # Русская документация
```
