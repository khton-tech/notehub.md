# Bootloader

**ID:** `nh.system.bootloader`  
**Пакет:** `@notehub/bootloader`  
**Путь:** `packages/plugins/system/bootloader/`

## Описание

Оркестратор загрузки плагинов с разрешением зависимостей. Реализует топологическую сортировку (алгоритм Кана) для определения порядка загрузки.

## Функционал

- **Валидация манифестов** — проверка с помощью Zod-схемы
- **Граф зависимостей** — построение и разрешение
- **Послойная загрузка** — параллельная загрузка плагинов в "волнах"
- **Каскадные ошибки** — если плагин падает, его зависимые тоже не загружаются

## Зависимости

Нет зависимостей (загружается первым).

## API

Bootloader не регистрирует публичных API-методов. Он используется ядром для инициализации остальных плагинов.

## Пример использования

```typescript
import { NotehubCore } from '@notehub/core';
import { BootloaderPlugin } from '@notehub/bootloader';

const core = new NotehubCore();
core.registerPlugin(new BootloaderPlugin());
// ... регистрация остальных плагинов
await core.init();
```
