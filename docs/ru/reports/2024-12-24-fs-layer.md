# Сессия 2024-12-24: FS Layer

## Цель
Реализация слоя работы с файловой системой (FS Layer) с разделением абстракции и реализации.

## Реализовано

### Плагины

#### @notehub/fs-manager (Абстракция)
**Путь:** `packages/plugins/system/fs-manager/`

Интерфейс `IFileSystem`:
- `readFile(path)` — чтение бинарного файла
- `readTextFile(path)` — чтение текстового файла  
- `writeFile(path, data)` — запись бинарных данных
- `writeTextFile(path, content)` — запись текста
- `createDir(path, options)` — создание директории
- `readDir(path)` — чтение содержимого директории
- `exists(path)` — проверка существования

**API методы:**
| Метод | Описание |
|-------|----------|
| `fs:register-driver` | Регистрация драйвера FS |
| `fs:read-file` | Проксирование к драйверу |
| `fs:write-file` | Проксирование к драйверу |
| ... | Все методы IFileSystem |

---

#### @notehub/fs-driver-tauri (Реализация)
**Путь:** `packages/plugins/system/fs-driver-tauri/`

- Реализует `IFileSystem` через `@tauri-apps/plugin-fs`
- При загрузке автоматически регистрируется в `fs-manager`
- Выводит в консоль: `FS Driver Registered: Tauri`

**Зависимость:** `nh.system.fs-manager` (загружается первым)

---

### Desktop приложение

#### Tauri V2 конфигурация
- `src-tauri/tauri.conf.json` — основной конфиг
- `src-tauri/Cargo.toml` — Rust зависимости (`tauri-plugin-fs`)
- `src-tauri/capabilities/default.json` — права доступа к FS
- `src-tauri/src/main.rs` — инициализация плагинов

#### Entry Point
`apps/desktop/src/main.tsx`:
```typescript
const core = new NotehubCore();
core.registerPlugin(new FsManagerPlugin());
core.registerPlugin(new FsDriverTauriPlugin());
await core.init();
```

## Исправления

1. **Дубликат плагинов в реестре**
   - Обновлён `scripts/link-plugins.ts`
   - Добавлено исключение `node_modules/` и `dist/`
   - Добавлена дедупликация по ID

2. **Tauri v2 конфиг**
   - Удалён невалидный `plugins.fs.scope`
   - В Tauri v2 используются capabilities

3. **Детекция Tauri окружения**
   - Изменено с `__TAURI__` на `__TAURI_INTERNALS__`
