# Предложение по расширению настроек приложения (Settings Expansion)

## Текущее состояние
На данный момент в приложении `notehub.md` реализован базовый набор настроек, который включает:
- **Внешний вид (Theme):** Выбор темы (Светлая/Темная/Системная), цвет акцента.
- **Редактор (Editor):** Размер шрифта, нумерация строк, перенос слов.
- **Проводник (Explorer):** Скрытие файлов, папки в начале списка.
- **Горячие клавиши (Hotkeys), Плагины, Инфо.**

Для обеспечения большей гибкости и удобства (как в современных IDE, например, VS Code или Obsidian), предлагается внедрить следующий список новых настроек.

---

## Предлагаемые новые настройки

### 1. Настройки редактора (Editor)
*Вкладка "Редактор" (Editor)*

| Ключ (Key) | Тип | Значение по умолчанию | Описание | Зачем нужно |
| :--- | :--- | :--- | :--- | :--- |
| `editor.tab-size` | `number` | `4` | Размер табуляции (в пробелах) | Базовая потребность для форматирования кода и текста. |
| `editor.auto-close-brackets` | `toggle` | `true` | Автоматическое закрытие скобок и кавычек | Ускоряет набор текста пользователем. |
| `editor.font-family` | `text` | `""` | Пользовательский шрифт для редактора | Позволяет пользователям использовать любимые моноширинные шрифты (например, Fira Code). |
| `editor.format-on-save` | `toggle` | `false` | Авто-форматирование при сохранении | Полезно при работе с кодом и маркдауном для поддержания единого стиля. |

### 2. Настройки файлов и сохранения (Files & Saving)
*Новая группа в "Редакторе" или "Файлах"*

| Ключ (Key) | Тип | Значение по умолчанию | Описание | Зачем нужно |
| :--- | :--- | :--- | :--- | :--- |
| `file.autosave` | `toggle` | `false` | Автосохранение файлов при изменении | Предотвращает потерю данных при случайном закрытии. |
| `file.autosave-delay` | `number` | `1000` | Задержка автосохранения (мс) | Контролирует частоту записи на диск (оптимизация I/O). |

### 3. Настройки Проводника (Explorer)
*Вкладка "Файлы" (Files)*

| Ключ (Key) | Тип | Значение по умолчанию | Описание | Зачем нужно |
| :--- | :--- | :--- | :--- | :--- |
| `explorer.confirm-delete` | `toggle` | `true` | Подтверждение при удалении файлов | Защита от случайного удаления важных заметок. |
| `explorer.single-click-open` | `toggle` | `true` | Одинарный клик для открытия файла | Позволяет выбрать стиль навигации (как в веб-браузере vs как в ОС). |

### 4. Настройки UI / Интерфейса (App / UI)
*Новая вкладка "Интерфейс" (UI) или группа в "Внешний вид"*

| Ключ (Key) | Тип | Значение по умолчанию | Описание | Зачем нужно |
| :--- | :--- | :--- | :--- | :--- |
| `ui.animations` | `toggle` | `true` | Включить анимации интерфейса | Отключение полезно для слабых устройств или для экономии батареи ноутбука. |
| `ui.sidebar-width` | `number` | `250` | Ширина боковой панели по умолчанию | Дает возможность настроить рабочее пространство (если ширину можно менять и сохранять). |

---

## План внедрения

1. **Регистрация новых ключей:** Добавление ключей в соответствующие конфигурационные файлы (`EditorConfig.ts`, `ExplorerConfig.ts` и т.д.).
2. **Обновление интерфейсов (UI):** Регистрация свойств через `app.api.invoke('settings:register-item')`.
3. **Интеграция в логику:**
   - Редактор: связать новые ключи (например, `tab-size`, `auto-close-brackets`) с инстансом `CodeMirror`.
   - Проводник: привязать диалог подтверждения удаления к `confirm-delete`.
   - Общее: реализовать логику отложенного `autosave` в контроллере редактора.
