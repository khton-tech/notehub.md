# UI/UX Audit Report: Notehub.md vs Obsidian

## 1. Введение
В ходе аудита было проведено сравнение текущей реализации интерфейса **Notehub.md** (на основе кодовой базы `theme-manager` и `ck-standart`) с эталонным дизайном **Obsidian**.
Текущий интерфейс Notehub.md использует дизайн-систему, близкую к Material/VS Code "Deep Space" (темная тема), однако наблюдаются проблемы с визуальной иерархией, "кислотностью" акцентных цветов и избыточным визуальным шумом от границ (borders). Obsidian, напротив, отличается минимализмом, где иерархия строится на отступах и типографике, а не на явных разделителях.

## 2. Gap Analysis (Сравнение)

| Критерий | Notehub.md (Current) | Obsidian (Reference) | Рекомендация | Модуль |
| :--- | :--- | :--- | :--- | :--- |
| **Акцентный цвет** | Яркий, сплошной (напр. `#6b5ce7` или Orange). "Кислотный" эффект. | Приглушенный, часто используется с прозрачностью (alpha-channel). | Использовать HSL цвета и снизить насыщенность для фона элементов. Сплошной цвет оставить только для мелких деталей (курсор, активный чекбокс). | `theme-manager` |
| **Границы (Borders)** | Явные, сплошные линии (`#3a3a3a` в `Card.tsx`). Высокий контраст. | Почти отсутствуют или очень тонкие/полупрозрачные. Разделение за счет фона (Surface layers). | Заменить сплошные границы на `rgba(255, 255, 255, 0.06)` или убрать их вовсе для карточек, оставив только при наведении. | `theme-manager` / `ck-standart` |
| **Чекбоксы** | Стандартный квадрат `w-4 h-4` с рамкой. | Круглые (для задач) или скругленные квадраты, меняющие опасити. | Сделать чекбоксы более "органичными" (radius `sm` -> `md`), добавить фоновую подсветку при наведении (glow effect). | `ck-standart` |

| **Типографика** | Дефолтный `system-ui`. | Inter или схожий гротеск. Тонкая работа с `font-weight`. | Подключить качественный веб-шрифт (Inter/Roboto) как дефолтный. Увеличить line-height для читаемости (1.6 для текста). | `theme-manager` |

## 3. Детальные рекомендации

### 3.1. Сайдбар и Навигация
*   **Проблема:** В текущей теме (`bg-sidebar: #232323`) сайдбар почти сливается с основным фоном (`bg-main: #1a1a1a`), либо разделен жесткой границей.
*   **Решение:**
    *   Сделать сайдбар более прозрачным или использовать noise-texture (опционально).
    *   Увеличить отступы (padding) в дереве файлов. Сейчас элементы списка могут казаться "сжатыми". Obsidian использует достаточно "воздушный" список (padding-y ~4px..6px).
    *   Иконки папок/файлов должны быть приглушенными (`text-muted`), становясь яркими только при наведении или активном состоянии.

### 3.2. Компоненты (`ck-standart`)
*   **Input (`Input.tsx`):** Сейчас имеет явный border (`border-subtle`). В "премиальных" интерфейсах инпуты часто имеют только нижнюю границу или фон без границы (filled style), появляющуюся при фокусе.
*   **Card (`Card.tsx`):**
    *   Сейчас: `border border-[var(--nh-border-secondary)]`.
    *   Рекомендация: Убрать border по умолчанию. Использовать его только для `variant="interactive:hover"`. Для разделения контента использовать чередование фона (`bg-surface` vs `bg-main`).

### 3.3. Цвета и Тема (`theme-manager`)
Необходимо переработать палитру `Deep Space` для снижения визуального шума.

**Предлагаемая палитра (пример для внедрения):**
```typescript
// Вместо жестких HEX использовать RGBA для границ для лучшего блендинга
'border-secondary': 'rgba(255, 255, 255, 0.08)', // Было #3a3a3a
'border-subtle': 'rgba(255, 255, 255, 0.04)',

// Акцент (вместо кислотного оранжевого/фиолетового)
// Если нужен оранжевый, но "премиальный":
'accent-primary': '#f97316', // Orange-500 (Tailwind base), но лучше использовать HSL
// Для Obsidian-style Purple:
'accent-primary': '#7c3aed', // Violet-600, но чуть темнее

// Текст
'text-muted': 'rgba(255, 255, 255, 0.45)', // Полупрозрачность лучше читается на разных фонах
```

## 4. Action Plan (План действий)

Приоритет задач по рефакторингу:

1.  **[High] Ревизия токенов цвета (`theme-manager`):**
    *   Заменить сплошные цвета границ на полупрозрачные (alpha-based).
    *   Внедрить новые переменные для теней (`box-shadow`).
    *   Настроить "премиальный" акцентный цвет (HSL).

2.  **[High] Рефакторинг базовых компонентов (`ck-standart`):**
    *   `Card.tsx`: Убрать границы по умолчанию, добавить легкую тень.
    *   `Checkbox.tsx`: Обновить стиль (скругление, анимация checked state).
    *   `Input.tsx`: Упростить дизайн, убрать "шумные" границы.

3.  **[Medium] Типографика и Spacing:**
    *   Внедрить глобальные настройки `line-height` и `font-weight` в `injectGlobalStyles` (`theme-manager`).
    *   Настроить отступы в списках файлов (это потребует правки в плагине `features/explorer`, который использует эти стили).

4.  **[Low] Микро-анимации:**
    *   Добавить плавные переходы (transition) на 200ms для всех интерактивных элементов (уже частично есть в `Card`, распространить на все).
